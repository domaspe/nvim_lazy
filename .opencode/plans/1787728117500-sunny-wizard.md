# Poll tmux theme every five seconds

## Implementation

- Update `lua/plugins/colorscheme.lua` in the onedark plugin's `init` function.
- Start a repeating Neovim timer with a 5000 ms interval after registering the existing `FocusGained` and `VimResume` autocmd.
- Reuse `apply_tmux_theme` as the timer callback so polling only reloads onedark when `vim.o.background` must change.
- Preserve the existing startup lookup, immediate focus/resume updates, and dark-style reset.

## Verification

- Run `nvim --headless "+qa"` to confirm the configuration starts without errors.
- In a tmux session, keep Neovim focused, change `@theme` to `light`, and confirm onedark switches within five seconds.
- Change `@theme` back to `dark` and confirm onedark returns to its `darker` style within five seconds.
- Change `@theme` while Neovim is unfocused, refocus it, and confirm the existing immediate focus-based switch still works.
